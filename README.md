Proyecto de Grafos - Matemáticas Discretas 2

- ¿Por qué elegí esta representación de grafo?

Para representar los grafos dirigidos y no dirigidos escogí la 
lista de adyacencia implementada con diccionarios en 
Python, ya que me pareció la opción más sencilla, intuitiva y 
fácil de entender. Llevaba bastante tiempo sin programar en 
Python, por lo que después de unas horas haciendo un repaso 
general del lenguaje, esta representación fue la forma más 
simple y directa que encontré para construir el grafo desde 
los archivos y recorrer sus vecinos. En general, el 
desarrollo del proyecto fue una buena experiencia para 
retomar la sintaxis de Python y familiarizarme con el flujo 
de trabajo usando uv y GitHub.
